## Descrição
O site foi feito com um intuito de ser um site para um cinema contendo um o catálogo de filmes disponíveis, o horário de cada um, além da compra de ingressos online
##  Páginas
- index.html:  Menu da página
- horarios.html: Tabela dos horários dos filmes
- filmes.html:  Filmes que estão em cartaz
- compra.html:  Local para efetuar o pagamento

## Uso do Flexbox
index.html
Foi usado na partes dos botões e parágrafo para deixar eles alinhados foi usado o align-items e para da um espaço entre os elementos foi usado o gap e flex-wrap para quebrar linha
Foi usado no destaque para deixar as fotos alinhadas uma no lado da outra e foi usado o gap para da espaços e flex-wrap para quebrar linha e dentro dos banner foi colocado flex para deixa a foto e o texto um no lado do outro e foi usado no final para fazer o um tipo de um rodapé usando justify-content:space-around e align-items:center 
horarios.html
flex foi usado para fazer a barra de navegação que esta encima do da pagina usando o justify-content: space-around e aling-items: center, foi usado nos botoes também par deixar eles de lado e fois usado no rodape usando o flex-direction column e align-items center
filmes.html
foi usado para deixar varios banner um no lado do outro e foi usado o flex-wrap: wrap para quebrar linha e o gap para separar os itens e foi usado flex dentro dos cartoes e foi usado flex-direction: column e gap
compra.html
foi usado para fazer os cartoes para deixar os cartoes um do lado do outro e foi usado dentro dos cartões usando o flex-directio:column e foi usado no registro para deixar duas colunas para preencher e a mesma coisa foi feita na forma de pagamento
obs:
todos os sites utilizou o mesmo sistema de flex na barra de navegação que fica encima de cada pagina, menos da pagina inicial que nao tem a barra de navegação, mas tem os botoes
